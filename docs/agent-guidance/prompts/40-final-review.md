# Prompt 40: final implementation review

```text
Review the completed local implementation without making further changes.

Compare the final diff with the approved plan and acceptance criteria.

Report:

1. files changed and purpose of each change;
2. behavior implemented and any deviation from the approved plan;
3. unrelated or accidental changes;
4. public API, configuration, schema, data, runtime, and protocol compatibility;
5. security review of inputs, authentication, authorization, secrets, logs,
   errors, dependencies, and failure paths;
6. performance review of calls, queries, paging, batching, filtering, caching,
   retries, concurrency, allocations, memory, and scale;
7. tests and checks actually executed, with exact outcomes;
8. validation not executed and why;
9. source conflicts, assumptions, limitations, and remaining risks;
10. rollback or recovery considerations;
11. current Git status and diff summary.

Classify the result as:
- ready for commit approval;
- conditionally ready with named follow-up;
- not ready because of blocking issues.

Do not call the change secure, performant, compatible, or merge-ready without
evidence for the affected behavior. Do not commit, push, or modify files. Wait
for user direction.
```
